SuperAI Monitor

GitHub Actions 在云端扫链，手机只负责收推送。电脑关机也不影响。

准备就绪
查看工作路径 →
1. 点“开启通知”，允许通知；
2. 点“复制订阅 JSON”；
3. 到 GitHub 仓库 Settings → Secrets and variables → Actions；
4. 新建 Secret：PUSH_SUBSCRIPTION，粘贴 JSON；
5. 再建 VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY（见 README）；
6. 在 Actions 里手动跑一次 “SuperAI Monitor” 测试。
